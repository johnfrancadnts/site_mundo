OpenWord — cores originais, logo suave e exclusão no perfil

O que foi ajustado nesta versão:
- Restaurada a folha de estilos responsiva sem as alterações que suavizavam as cores do site inteiro. A paleta original do OpenWord volta a ser usada nos botões, filtros, destaques, cartões e demais elementos.
- Somente a palavra “Word” na logo do canto superior esquerdo usa um verde suave sem neon.
- Na página de perfil, os anúncios publicados pela conta autenticada exibem o botão “Apagar”.
- O botão de exclusão continua disponível nos cartões da vitrine para os anúncios do próprio usuário.
- A exclusão pede confirmação e verifica o proprietário autenticado. Anúncios de outras contas não exibem o botão.
- Ao apagar um anúncio enquanto estiver na página do perfil, a lista e a contagem de imóveis são atualizadas sem precisar sair da página.

Para publicar:
1. Faça uma cópia de segurança dos arquivos atuais.
2. Extraia o ZIP e envie os arquivos para o repositório GitHub, mantendo as pastas css e js.
3. Faça commit e aguarde o GitHub Pages atualizar.
4. Abra o site e pressione Ctrl + F5.

Observação: a exclusão no site publicado depende de as regras do Firestore permitirem que o proprietário autenticado exclua apenas os próprios documentos em properties. O arquivo firestore.rules incluído contém essa regra. Se as regras ainda não foram publicadas no Console Firebase, publique-as também.

Os scripts JavaScript foram verificados com node --check e o arquivo ZIP foi testado. Isso não substitui um teste manual no site publicado com uma conta autenticada.
